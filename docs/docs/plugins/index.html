Plugins

This configuration uses lazy.nvim to manage the plugins below. They are installed automatically on the first launch; run :Lazy to inspect them and :Lazy update to update.

Completion Engine

Autocompletion powered by nvim-cmp with multiple sources for context-aware suggestions.

PluginDescription
nvim-cmpMain completion engine that provides intelligent autocompletion
cmp-nvim-lspLSP source for nvim-cmp, enables IDE-style completions from language servers
cmp-bufferSuggests words and identifiers from open buffers
cmp-pathAutocompletes file system paths and directory structures
cmp_luasnipIntegrates Luasnip snippets into the completion menu
LuaSnipSnippet engine with support for Lua-based snippet definitions
friendly-snippetsPre-built snippet collection for many programming languages

Language Server Protocol (LSP)

Full LSP integration for code intelligence including diagnostics, hover info, go-to-definition, and more.

PluginDescription
nvim-lspconfigPre-configured setups for common language servers
fidget.nvimDisplays LSP progress indicators in a small unobtrusive window

UI & Aesthetics

Visual enhancements that make Neovim look and feel modern.

PluginDescription
neovim-ayuayu-dark colorscheme used as the default theme
lualine.nvimGlobal statusline using the matching ayu theme
snacks.nvimStart dashboard with file, project, and keymap shortcuts
bufferline.nvimTab-like buffer line at the top of the window for easy navigation between open files
neo-tree.nvimModern file explorer with a tree view, git integration, and file operations (v3.x branch)
nui.nvimUI component library used by other plugins (dependency)
nvim-web-deviconsFile icons for the statusline and file explorer (dependency)
indent-blankline.nvimDisplays vertical guides to visualize indentation levels
mini.indentscopeHighlights the indent scope of the current cursor position
nvim-highlight-colorsShows actual color previews for hex codes, CSS variables, and color names
render-markdown.nvimRenders markdown files with formatted headings, lists, checkboxes, and code blocks
toggleterm.nvimToggleable horizontal terminal
todo-comments.nvimHighlights TODO comments and related keywords
cord.nvimDiscord Rich Presence integration

Version Control (Git)

Git integration for tracking changes and managing repositories without leaving Neovim.

PluginDescription
gitsigns.nvimShows git diff hunks in the sign gutter with inline blame preview and hunk actions
lazygit.nvimOpens the Lazygit TUI inside a Neovim floating window for full git management

Editing Utilities

Tools that streamline everyday editing tasks.

PluginDescription
nvim-treesitterTree-sitter based syntax highlighting and indentation; parsers are updated with :TSUpdate
nvim-autopairsAutomatically inserts closing pairs like brackets, quotes, and parentheses
nvim-ts-autotagUses Tree-sitter to auto-close and auto-rename HTML/XML/JSX tags
code_runner.nvimRun code directly from Neovim with language-aware commands
plenary.nvimLua utility library used by Telescope and Neo-tree (dependency)

Fuzzy Finding

PluginDescription
telescope.nvimFuzzy finder for files, buffers, text, and keymaps
telescope-ui-select.nvimRoutes vim.ui.select prompts through a Telescope dropdown
