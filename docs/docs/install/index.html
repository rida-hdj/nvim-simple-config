Installation

Requirements

Before installing, make sure the following dependencies are available on your system.

System Dependencies

ToolPurpose

ToolPurpose

Language Server Protocol (LSP)

Install the appropriate language servers for the languages you work with. Each server provides IDE-like features such as autocomplete, go-to-definition, and diagnostics. The config enables these servers with vim.lsp.enable:

ServerLanguage
lua_lsLua
clangdC / C++
pyrightPython
rust_analyzerRust
htmlHTML
csslsCSS
ts_lsJavaScript / TypeScript
nil_lsNix
marksmanMarkdown

Backup Existing Config

If you already have a Neovim configuration, back it up before proceeding. This ensures you can restore it later if needed.

Linux / macOS

mv ~/.config/nvim ~/.config/nvim_backup

Windows (PowerShell)

Move-Item $env:LOCALAPPDATA\nvim $env:LOCALAPPDATA\nvim_backup

Installation

Clone the repository into your Neovim configuration directory.

Linux / macOS

git clone --depth 1 https://github.com/rida-hdj/nvim-simple-config.git ~/.config/nvim

Windows (PowerShell)

git clone --depth 1 https://github.com/rida-hdj/nvim-simple-config.git $env:LOCALAPPDATA\nvim

Post-Installation

  1. Open Neovim to install lazy.nvim and all plugins automatically:

    nvim

  2. Wait for the plugin manager to finish installing dependencies and Tree-sitter parsers.

  3. Restart Neovim once installation is complete.

  4. Run :Lazy at any time to inspect, update, or clean the installed plugins.
